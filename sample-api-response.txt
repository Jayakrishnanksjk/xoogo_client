================================================================================
XOOGO - Sample API Response
================================================================================

Endpoint : GET /api/sync/full-timetable?bus_id=<uuid | busId>
Auth      : X-API-Key header (per-bus key, e.g. default_bus_key)
Result    : HTTP 200 OK

Example call:
  curl -H 'x-api-key: default_bus_key' \
       'https://<server>/api/sync/full-timetable?bus_id=1FH7QZ'

Note:
  - Each schedule's "route" is a single ROUTE OBJECT (no sequenceOrder wrapper; was "routes": [...])
  - Every stop now includes a "sequenceOrder" integer (driving order, ascending)
