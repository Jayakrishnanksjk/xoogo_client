## Authentication

XOOGO uses **three different authentication mechanisms** depending on the endpoint you are calling.

### 1. JWT Bearer Token (Management APIs)

Used by the web dashboard. Login first, then send the returned token:

```
Authorization: Bearer <JWT_TOKEN>
```

- Token expiry: `7 days` by default (configurable via `JWT_EXPIRES_IN`).
- On expiry the API returns `401` with `message: "Token expired. Please login again."`
- Roles: `superadmin` (full access), `admin`, `partner`, `operator`. Access is enforced per endpoint — e.g. user management requires `superadmin` or `admin`; API-key and branding management require `superadmin`; bus/route/schedule/group management accepts any authenticated user.

### 2. Per-Bus API Key (Public Bus APIs)

Used for external app integration to read bus/route/schedule data for a specific bus. Each bus can have its own key, generated by a superadmin from the dashboard (Settings → Integrations). Key format:

```
bus_<48 hex characters>
```

Send it in the Authorization header:

```
Authorization: Bearer bus_<48 hex characters>
```

- Requires `busId` in the request body.
- Keys can be revoked; revoked keys return `401`.

### 3. Shared Device API Key (Transit / Sync APIs)

Used by the on-bus Android TV devices. A single shared key configured on the server via `BUS_API_KEY` environment variable.

```
x-api-key: <BUS_API_KEY>
```

## Common Error Format

Every error response uses the same shape:

```json
{
  "message": "Human-readable description of the error"
}
```

### HTTP Status Codes

| Code | Meaning |
| --- | --- |
| `200` | Success |
| `201` | Resource created |
| `400` | Bad request — missing/invalid fields |
| `401` | Unauthorized — missing/invalid credentials or API key |
| `403` | Forbidden — authenticated but insufficient permissions |
| `404` | Resource not found |
| `409` | Conflict — duplicate email, code, etc. |
| `500` | Internal server error |

### Auth

#### `POST /api/auth/login`

Authenticate a user and get a JWT token.

**Request body:**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `email` | string | yes | Lower-cased and trimmed |
| `password` | string | yes | |

**Request example:**

```json
{
  "email": "admin@xoogo.com",
  "password": "your_password"
}
```

**Response `200`:**

```json
{
  "token": "<JWT_TOKEN>",
  "user": {
    "id": "0a2e12f4-...",
    "full_name": "Admin User",
    "email": "admin@xoogo.com",
    "phone": "+91 90000 00000",
    "role": "superadmin",
    "status": "active",
    "group": "All Groups",
    "last_login_at": "2026-08-01T09:00:00.000Z",
    "created_at": "2026-01-01T00:00:00.000Z"
  }
}
```

**Errors:**

- `400` — Email and password are required.
- `401` — Invalid credentials.
- `403` — Your account is deactivated.

#### `GET /api/auth/me`

Return the currently authenticated user.

**Auth:** JWT Bearer

**Response `200`:** Same `user` object as login, without the token.

#### `POST /api/auth/logout`

**Auth:** JWT Bearer

**Response `200`:**

```json
{
  "success": true,
  "message": "Logged out successfully."
}
```

### Public Bus APIs

These are the primary endpoints for external app integration. Authenticate with a **per-bus API key**.

> Note: these endpoints use `POST` with the `busId` in the body.

#### `POST /api/public/bus`

Get basic details of a single bus.

**Auth:** Per-bus API key (`Authorization: Bearer bus_...`)

**Request body:**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `busId` | string | yes | 6-character bus identifier, e.g. `X1A2B3` |

**Request example:**

```json
{
  "busId": "X1A2B3"
}
```

**Response `200`:**

```json
{
  "regNumber": "KL-07-AB-4521",
  "busId": "X1A2B3",
  "busType": "AC Low Floor",
  "status": "online",
  "contactName": "Ramesh Kumar",
  "contactNumber": "+91 98765 43210",
  "group": {
    "id": "a1b2c3d4-...",
    "name": "Kochi Metro Fleet"
  },
  "route": {
    "id": "5f6a7b8c-...",
    "name": "Downtown Express",
    "code": "D001"
  }
}
```

**Errors:**

- `400` — busId is required.
- `401` — API key required / Invalid or revoked API key.
- `404` — Bus not found.

### Transit / Device Sync APIs

Used by on-bus devices (Android TV screens). Authenticate with the shared **device API key** in the `x-api-key` header.

#### `GET /api/sync`

Get the route, stops, and estimated travel times (ETAs) for a bus, used to initialize the on-device trip data.

**Auth:** Device API key (`x-api-key: <BUS_API_KEY>`)

**Query parameters:**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `bus_id` | string | yes | The bus's UUID `id` **or** its 6-char `busId` (e.g. `XUT54N`) — both resolve to the same bus |

The response's `bus_id` field always returns the bus's UUID `id`.

**Response `200`:**

```json
{
  "bus_id": "5b6c7d8e-...",
  "route": {
    "id": "5f6a7b8c-...",
    "name": "Downtown Express",
    "polyline": null
  },
  "stops": [
    {
      "id": "8c9d0e1f-...",
      "name": "Central Station",
      "latitude": 10.0123,
      "longitude": 76.1234,
      "sequenceOrder": 1
    },
    {
      "id": "1a2b3c4d-...",
      "name": "Market Square",
      "latitude": 10.0345,
      "longitude": 76.1456,
      "sequenceOrder": 2
    },
    {
      "id": "2b3c4d5e-...",
      "name": "University Gate",
      "latitude": 10.0567,
      "longitude": 76.1678,
      "sequenceOrder": 3
    },
    {
      "id": "3c4d5e6f-...",
      "name": "City Hospital",
      "latitude": 10.0789,
      "longitude": 76.1890,
      "sequenceOrder": 4
    }
  ],
  "etas": [
    {
      "fromStopId": "8c9d0e1f-...",
      "toStopId": "1a2b3c4d-...",
      "averageDurationSeconds": 240
    },
    {
      "fromStopId": "1a2b3c4d-...",
      "toStopId": "2b3c4d5e-...",
      "averageDurationSeconds": 300
    },
    {
      "fromStopId": "2b3c4d5e-...",
      "toStopId": "3c4d5e6f-...",
      "averageDurationSeconds": 300
    }
  ]
}
```

`etas` contains one entry per consecutive stop pair. If no historical data exists, `averageDurationSeconds` defaults to `300`.

#### `GET /api/sync/full-timetable`

Purpose-built one-call bootstrap for on-bus devices: returns the bus's full details, all its active schedules, and every route (with the complete embedded `stops` array) in a single response. Use this for the first-boot / daily offline download instead of making separate `/sync` and `/public/bus-schedule` calls.

**Auth:** Device API key (`x-api-key: <BUS_API_KEY>`)

**Query parameters:**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `bus_id` | string | yes | The bus's UUID `id` **or** its 6-char `busId` (e.g. `XUT54N`) — both resolve to the same bus |

The response's `bus_id` field always returns the bus's UUID `id`.

**Response `200`:**

```json
{
  "bus_id": "5b6c7d8e-...",
  "bus": {
    "id": "5b6c7d8e-...",
    "busId": "X1A2B3",
    "regNumber": "KL-07-AB-4521",
    "busType": "AC Low Floor",
    "status": "online",
    "contactName": "Ramesh Kumar",
    "contactNumber": "+91 98765 43210"
  },
  "schedules": [
    {
      "id": "4d5e6f70-...",
      "name": "Weekday Morning",
      "description": "Morning rush service",
      "status": "active",
      "startTime": "06:00:00",
      "endTime": "10:00:00",
      "route": {
        "id": "5f6a7b8c-...",
        "name": "Downtown Express",
        "code": "D001",
        "routeType": "outbound",
        "polyline": null,
        "stops": [
          {
            "id": "8c9d0e1f-...",
            "name": "Central Station",
            "sequenceOrder": 1,
            "latitude": 10.0123,
            "longitude": 76.1234
          },
          {
            "id": "1a2b3c4d-...",
            "name": "Market Square",
            "sequenceOrder": 2,
            "latitude": 10.0345,
            "longitude": 76.1456
          }
        ]
      }
    }
  ]
}
```

- Only `active` schedules are returned, ordered by `startTime` ascending.
- Each schedule's `route` is a single route object (the first `ScheduleRoute` by `sequenceOrder`); `stops` is the full ordered stop list for that route.
- A bus with no assigned schedules returns an empty `schedules` array.

**Errors:**

- `400` — Missing `bus_id` query parameter.
- `401` — Missing/invalid device API key.
- `404` — Bus not found.

#### `POST /api/events`

Log a trip event from a device.

**Auth:** Device API key

**Request body:**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `bus_id` | string | yes | The bus's UUID `id` **or** its 6-char `busId` (e.g. `XUT54N`) — both resolve to the same bus |
| `event` | string | yes | One of: `TRIP_STARTED`, `ARRIVED`, `DETOUR_STARTED`, `SKIPPED`, `TRIP_COMPLETED` |
| `stop_id` | string (UUID) | no | Stop associated with the event |
| `missed_stop_id` | string (UUID) | no | For `SKIPPED` events |
| `arrived_stop_id` | string (UUID) | no | Stop where the bus arrived |
| `cross_track_error` | string | no | Off-route distance/metric |
| `timestamp` | string (ISO 8601) | yes | Event time |
| `raw_timestamp` | string | no | Raw device timestamp |

**Request example:**

```json
{
  "bus_id": "5b6c7d8e-...",
  "event": "ARRIVED",
  "stop_id": "8c9d0e1f-...",
  "arrived_stop_id": "8c9d0e1f-...",
  "timestamp": "2026-08-01T08:15:00Z"
}
```

**Response `201`:**

```json
{
  "message": "Event logged",
  "id": "6e7f8091-..."
}
```

**Errors:**

- `400` — Missing required fields: bus_id, event, and timestamp are required.
- `400` — Invalid event type.

#### `POST /api/cron/run`

Aggregate today's event logs and recompute average segment durations (`HistoricalEta`). Typically triggered by a cron job on the server.

**Auth:** Device API key

**Response `200`:**

```json
{
  "message": "ETA aggregation complete",
  "updatedPairs": 12
}
```

## Data Dictionary

### Bus

| Field | Type | Description |
| --- | --- | --- |
| `id` | UUID | Primary key, used in transit/device APIs |
| `busId` | string | 6-character short code for public APIs (e.g. `X1A2B3`) |
| `regNumber` | string | Registration number (unique) |
| `simNumber` | string | SIM card number |
| `busType` | string | e.g. `AC Low Floor` |
| `contactName` | string | Bus contact person |
| `contactNumber` | string | Contact phone |
| `chassisNumber` | string | (optional) |
| `model` | string | (optional) e.g. `Tata Starbus` |
| `status` | string | `online` \| `offline` |
| `groupId` | UUID | Owning group |
| `routeId` | UUID | (optional) Assigned route |
| `group` | object | Nested: `{ id, name }` |
| `route` | object | Nested: `{ id, name, code }` (public) or `{ id, name }` (management) |
| `schedules` | array | Nested schedule objects |

### Route

| Field | Type | Description |
| --- | --- | --- |
| `id` | UUID | Primary key |
| `name` | string | Route name |
| `code` | string | Unique route code (e.g. `D001`) |
| `estimatedDuration` | string | e.g. `45 mins` |
